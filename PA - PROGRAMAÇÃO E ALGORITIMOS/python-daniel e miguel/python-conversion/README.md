# O que aprendemos com os exercícios

Com esses exercícios, aprendemos a aplicar conceitos básicos de lógica de programação usando **C++ e Python**. Praticamos estruturas de decisão, como `if` e `else`, e estruturas de repetição, principalmente o `while`.

Também aprendemos a trabalhar com **entrada e saída de dados**, comparação de números, cálculos matemáticos, validação de informações, contadores, acumuladores e condições. Além disso, entendemos como transformar um programa escrito em C++ para uma versão equivalente em Python, adaptando a sintaxe de cada linguagem.

Os exercícios também ajudaram a desenvolver a capacidade de **testar, identificar erros e melhorar os programas**, além de praticar a organização de projetos e o uso do **GitHub e de commits** para acompanhar a evolução do trabalho.
